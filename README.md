# ClaxTeam

Sprechen, ohne etwas zu fordern.

Clax ist eine Arbeitsweise für Mensch und KI im selben Team. Sie ist
offen, personenneutral und an kein Werkzeug gebunden.

## Was hier liegt

- `skills/clax-framework/SKILL.md` Die Arbeitsweise als Skill: 4D-Analyse, Klartext, klare Zuständigkeit.
- `texte/wert-als-eintrittskarte.md` Der Grundsatz dahinter.

## So nutzt du es

Lade die Datei `SKILL.md` als Skill oder als Anweisung in den
KI-Assistenten deiner Wahl. Der Text ist vollständig, es braucht nichts
weiter dazu.

## Stand

Fassung 3 ist einmal getestet worden, in der Fassung davor. Der Test hat

## Wer hier Regeln ändert

Vorschlagen kann jeder, über einen Pull Request. Übernommen wird eine
Änderung nur vom Inhaber dieses Repos. Das ist eine bewusste Grenze: Ein
Regelwerk braucht eine Person, die dafür geradesteht.
